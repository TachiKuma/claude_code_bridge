# Iteration 001

## Current Understanding

本轮目标不是发布 Windows npm 或把 Rmux 宣布为 `supported`，而是把安装、打包、诊断和文档契约收口到同一个证据驱动 projection。当前 full validation matrix 已是 `pass`，但缺少 local install smoke 和 package gate，因此支持档必须 fail closed 到 `beta`，并通过 doctor、installer、docs 和测试保持一致。

## Implementation Approach

采用单一 owner 模块维护支持档判定：Python 负责从 route approval、capability、validation matrix、local install smoke、package gate 等证据计算 projection；PowerShell installer 只读取已打包 projection 并做本机 rmux prerequisite 检测。这样避免 README、doctor、install.ps1 各自硬编码支持状态。

未启用 Windows npm 路线：`package.json.os` 不加入 `win32`，Windows native Rmux 暂以 `install.ps1` / source route 作为 beta opt-in 入口。`install.ps1` 不下载或安装 rmux，只提供 `detect_only` / `warn` / `fail_fast` 检测策略。
